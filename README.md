# KanbanBoard
Personal Kanban board that can be run offline. [Run it here](https://charisalfan.github.io/KanbanBoard/)

# Feature
Add new task, delete task, edit task details, export all task for documentation report as a csv file.
Works offline since all data stored in browser. If all data in the browser is deleted, the data on the kanban board will be deleted.

# Offline
Want to run it offline without an internet connection? Simply download the index.html file and run it using your favorite browser.
